Exploring Values Across Asia

This page presents an exploratory analysis of synthetic (simulated) data fabricated to resemble the World Values Survey, Wave 7 (Haerpfer, C., Inglehart, R., et al., 2022, World Values Survey Wave 7). No real respondent data is used. Any patterns are illustrative only and should not be cited as real-world findings. The dataset covers five countries in different parts of Asia: China (East Asia), India (South Asia), Kazakhstan (Central Asia), Singapore (Southeast Asia), and Turkey (Middle East).
